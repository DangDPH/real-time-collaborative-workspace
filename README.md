# Whiteboard App 🎨

A simple **real-time canvas whiteboard** built with React and Konva.

## 🚀 Features
- 🟥 Add shapes (Rectangle, Circle)
- ✏️ Free drawing mode
- 🔤 Editable text (double-click to edit)
- 🖱 Drag & drop shapes
- 📐 Resize elements with Transformer

## 🛠 Tech Stack
- React
- Vite
- react-konva
- uuid

## 📦 Installation

```bash
GO TO FILE src/whiteboard-app
npm install
npm run dev
